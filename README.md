# BD Crop

 a data visualisation and simulation platform which will show information about crop(fruits also included) production in Bangladesh , and the effect of different factors such as (pollution , flood , river land , water level reduction , weather pattern , climate change(very general) etc ). 

## Features

Features:

	- Frontend based maps
			Heatmap (which crops is prevalent in which part of the country ,using     data weights based on how much was produced)
		
	- Interactable maps (users will be able to click on a district and see what kind of production in prevalent in a certain district , the effect of the previously mentioned factors on the distinct(how much is it hurting the production ))
	
	- Charts (based on how much crops were produced , line charts for showing crops production year by year, bar chart for showing comparisons between two subjects , pie charts for giving overall/generalized  idea )

	- Simulation (very basic) users will be able to tinker with the aforementioned factors to 	examine what will happen in certain variable changes , very basic
	
## Tools

	- XAMPP server for the backend
	- The charts will use chart.js or other purely frontend based libraries
	- Mysql for Database
	- a small fuzzy search engine
	- Backend language : php

## Data Collection


    - Government websites    : BBS (Bangladesh bureau of statistics) 
    - International website  : FAO (Food and Agricultural organisation of the United Nations)
    - Other websites         : Kaggle
